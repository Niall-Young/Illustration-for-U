# Repository Guidelines

## Working Directory

- Treat this repository root as the main workspace.
- Check the nested project directory before making code changes.
- Prefer small, scoped edits that match the existing project structure.

## Commands

- Inspect available scripts from the relevant `package.json` before running build, lint, or test commands.
- Use `rg` for searching files and text when available.

## Change Policy

- Do not revert user changes unless explicitly requested.
- Keep unrelated files untouched.
- Verify changes with the narrowest relevant command before reporting completion.
